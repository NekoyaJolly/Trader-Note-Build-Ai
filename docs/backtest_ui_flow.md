# バックテスト機能 UI フロー

## 概要

バックテスト機能はストラテジー詳細に統合されており、`/strategies/[id]/backtest` で実行・結果表示を行います。

## 画面遷移

1. **ストラテジー一覧** (`/strategies`)
2. ストラテジー名をクリック → **ストラテジー詳細** (`/strategies/[id]`)
3. 「バックテスト」リンクをクリック → **バックテスト画面** (`/strategies/[id]/backtest`)

## バックテスト実行時の表示フロー

### 1. 実行ボタンクリック直後

- **「チェック中...」**: データカバレッジチェック中（スピナー表示）
- ボタンが無効化され、スピナーアイコンが表示される

### 2. データカバレッジダイアログ（データ不足時）

以下の場合に表示:

- 指定期間のOHLCVデータがDBに存在しない
- ダイアログ内の表示:
  - 「データがありません」またはカバレッジ不足の説明
  - **「APIからデータ取得（推奨）」**: cTrader API（優先）→ Twelve Data API（フォールバック）から取得
    - cTrader認証済みユーザー: 自アカウントの履歴データを無料で取得
    - 取得中: 進捗バー + 「ソース: ctrader」または「ソース: twelvedata」を表示
    - 取得成功後、自動でバックテストを実行
  - **「既存データのみ」**: 既存データだけで実行（データが少ないとエラーになる可能性）
  - **「キャンセル」**: ダイアログを閉じる

### 3. バックテスト実行中

- **「実行中...」**: ボタンにスピナー＋「実行中...」テキスト
- ボタンは無効（`disabled`）のまま
- バックテストAPIが完了するまで待機（数十秒〜数分）

### 4. 結果表示（完了後）

- **サマリータブ**（デフォルト表示）:
  - ステータスバッジ: 「完了」「破産」「失敗」
  - メトリクスカード:
    - トレード数
    - 勝率 (%)
    - 期待値
    - 純損益
    - 最大連勝/連敗
  - その他指標（プロフィットファクター、最大ドローダウン等）

- **トレードタブ**: 個別トレード一覧（エントリー/決済日時、価格、損益等）
- **履歴タブ**: 過去のバックテスト実行履歴
- **その他タブ**: フィルター、ウォークフォワード、モンテカルロ、ノート検証、AI分析

## 注意事項

- バックテストにはOHLCVデータが必要。以下のいずれかで取得可能:
  - **cTrader API**: ログイン済みなら「APIからデータ取得」で自アカウントの履歴を自動取得
  - **Twelve Data API**: cTrader未設定・失敗時はTwelve Dataにフォールバック（無料枠制限あり）
  - **データプリセット**: 事前にCSVインポートしておく方法
- データが無い状態で「既存データのみ」を選択するとエラーになる
- バックテスト期間に制限なし（開始日＜終了日であれば任意の期間を指定可能）

## 確認コマンド

```bash
npm run test:e2e:production:backtest
```

認証済み（`.auth/production.json` あり）の状態で実行してください。
