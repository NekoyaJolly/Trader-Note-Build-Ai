# マクロ環境指標 定義一覧

TradeAssist Side-B AI が日次チェックするマクロ環境指標。
テクニカル分析の**補助レイヤー**として、トレード環境の大局を判断する。

## 指標一覧

| ID | 名称 | 役割 | 定義ファイル |
|----|------|------|-------------|
| vix | VIX（恐怖指数） | 市場リスク環境の判定 | [VIX.md](./VIX.md) |
| dxy | DXY（ドルインデックス） | ドル通貨の方向性 | [DXY.md](./DXY.md) |
| yields | 米国債利回り（2Y/5Y/10Y） | イールドカーブと金利環境 | [YIELDS.md](./YIELDS.md) |
| sp500 | S&P500 | リスクセンチメント | [SP500.md](./SP500.md) |

## テクニカル分析との関係

マクロ指標はテクニカル分析を**上書きしない**。以下の優先順位で判断する：

1. **マクロ環境チェック** → トレード環境が適切かを判断
2. **テクニカル分析** → エントリー方向・タイミングを決定
3. **マクロがテクニカルに影響するケース**:
   - VIX高(>30): テクニカル信頼性低下 → 新規エントリー見送り推奨
   - 重要イベント前後: テクニカルシグナル無効化の可能性大
   - リスクオフ: ドル建て資産のロングシナリオ信頼度を下げる

## 状態フラグ体系

マクロ指標は「数値→状態フラグ」に変換してAIに渡す：

| フラグ | 値 | 意味 |
|--------|-----|------|
| riskSentiment | `risk_on` / `neutral` / `risk_off` | リスク姿勢 |
| volatilityRegime | `low` / `normal` / `elevated` / `crisis` | ボラティリティ環境 |
| yieldCurveSignal | `normal` / `flattening` / `inverted` | イールドカーブ形状 |

## 共通ルール

- マクロ指標は**日次更新**で十分（分足でチェックする必要なし）
- データ取得できない場合は `neutral/normal` をデフォルト値とする
- マクロ判定は**トレードの方向性を変えない**。ポジションサイズと信頼度に反映する
