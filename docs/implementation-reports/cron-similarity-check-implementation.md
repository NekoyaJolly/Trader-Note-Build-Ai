## 📋 概要

Cron監視ジョブに、AIトレードノート（AITradeNote）および人間トレードノート（TradeNote）との類似度をチェックし、閾値を超えた場合に自動通知を送信する機能を追加しました。

### 目的
- 優位性パターンをリアルタイムで検知→ユーザーに即時フィードバック
- 人間ノート/AIノート双方での「今活かせるパターン」を逃さず活用
- 将来的なAgent化も見据えた類似性評価/通知インフラの整備

## 🔧 主要機能

### 1. 自動類似度チェック
- トリガー: Cron監視（1時間ごと）
- 対象: 監視対象シンボルの最新市場データ
- 検索範囲: TradeNote + AITradeNote（横断検索）
- 閾値: デフォルト85%（設定可能）

### 2. 自動通知
- 条件: 類似度が閾値以上
- チャネル: in-app / Push / webhook
- 抑制機能: 冪等性チェック、クールダウン、24時間上限

### 3. パフォーマンス最適化
- APIコスト: ゼロ（既存OHLCV取得を再利用）
- 実行頻度: 1時間ごと
- 検索効率: minSimilarity事前フィルタ + topK制限
