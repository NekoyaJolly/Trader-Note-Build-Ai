# 米国債利回り 定義書（US Treasury Yields）

## メタ情報
- indicator_id: `yields`
- カテゴリ: macro / interest-rate（マクロ・金利環境）
- 定義バージョン: 1.0.0

## 概要
米国債の利回り（2年、5年、10年）からイールドカーブの形状を判定する。
カーブ形状は景気サイクルの先行指標として広く認識されている。

## 対象利回り

| 利回り | 意味 |
|--------|------|
| 2年国債 | 短期金利期待（FRB政策に敏感） |
| 5年国債 | 中期金利期待 |
| 10年国債 | 長期成長/インフレ期待 |

## イールドカーブ判定

| 条件 | yieldCurveSignal | 意味 |
|------|-----------------|------|
| 2Y < 5Y < 10Y（スプレッド正常） | `normal` | 景気拡大期待。リスク資産に強気OK |
| 10Y - 2Y < 0.25% | `flattening` | 先行き不透明。慎重に |
| 2Y > 10Y（逆転） | `inverted` | リセッション警戒。リスク資産の強気信頼度を下げる |

## AIルール

- **normal**: マクロ要因からの制限なし
- **flattening**: シナリオのoverallConfidenceを5%減算。warningsに「イールドカーブフラット化」を記載
- **inverted**: リスク資産（株式、金のロング）の信頼度を10-15%減算。「リセッション警戒」をwarningsに含める

### 急変動チェック
- いずれかの利回りが日次で±10bp（0.10%）超の変動: 「金利急変動」をwarningsに含める
- 金利急変動時はボラティリティ拡大の先行シグナルとして扱う

## 注意事項
- イールドカーブ逆転 ≠ 即座にリセッション（先行指標、通常6-18ヶ月後）
- 利回りデータはクローズ時点の値を使用（日中変動は追わない）
- データなしの場合: `normal` として扱う
